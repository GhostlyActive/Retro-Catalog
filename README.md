# Retro-Catalog

A curated catalogue of 1432 retro games across 18 systems — tiers, verdicts and
grouping are mine, ratings and artwork come from ScreenScraper. Single HTML file:
plain HTML, CSS and a little JavaScript, no dependencies.

→ [ghostlyactive.github.io/Retro-Catalog](https://ghostlyactive.github.io/Retro-Catalog)
